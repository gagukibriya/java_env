# java_env
This repository is created for practicing Java code; if you clone this repository and run the script, everything will be set up automatically.

## Requirements

- Windows 10/11
- Git
- VS Code
- Internet connection
- Winget

## Installation

Clone repository:

    git clone https://github.com/gagukibriya/java_env.git

Open folder:

    cd java_env

Run setup:

    .\setup.ps1

Restart VS Code terminal.

## Start Practicing

Write Java code inside:

    YourCodeHere.java

Run:

    run

That's it!
