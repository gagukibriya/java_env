# java_env
This repository is created for practicing Java code; if you clone this repository and run the script, everything will be set up automatically.

## Requirements

- Windows 10/11
- Git
- Visual Studio Code
- Internet connection

## Installation

Clone the repository:

    git clone https://github.com/gagukibriya/java_env.git

Open the project folder:

    cd java_env

Run setup:

    powershell.exe -ExecutionPolicy Bypass -File .\setup.ps1

## Start Coding

Open VS Code:

    code .

Write your code inside:

    YourCodeHere.java

Run your code:

    powershell.exe -ExecutionPolicy Bypass -File .\run.ps1
